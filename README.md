# homebrew-groktree

Homebrew tap for [groktree](https://github.com/MaXFalstein/grok-build-wtree), a read-only inspector for Grok Build worktrees.

## Install

```sh
brew install maxfalstein/groktree/groktree
```

Or:

```sh
brew tap maxfalstein/groktree
brew install groktree
```

Alternatively:

```sh
cargo install groktree
```
